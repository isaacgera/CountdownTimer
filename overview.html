Countdown Timer

Idea Overview - one-page summary
Built - v1.2.4, live on GitHub Pages
Category: Productivity Complexity: Simple Local-first PWA

What it is

A simple, local-first app that counts down to the dates that matter - birthdays, deadlines, trips, anniversaries. Add a named event with a date (and optional time) and see the days remaining at a glance, kept sorted and filtered.

Who it's for

Anyone who wants a quick, no-fuss view of upcoming milestones without a calendar app's overhead - family dates, work deadlines, holidays and trips in one tidy list on their phone or desktop.

Why it's useful

It answers one question instantly - "how long until...?" - with no sign-in, no clutter and no data leaving the device. It installs as an app and works offline.

How it helps

  • Add, edit and delete named countdowns with category, notes and repeat options.
  • Live "days to go" with Today / soon / passed states and an optional hours-minutes sub-line.
  • Separate Upcoming and Past views (nearest first), with 10-per-page paging.
  • Recurring events - weekly / monthly / yearly or a custom "every N" interval - that roll forward automatically.
  • Mobile-first, installable PWA: gradient banner, bottom navigation on phones.
  • Personalise - 8 colour themes plus light & dark; keyboard and screen-reader friendly.
  • Export / import JSON backups that merge rather than overwrite.

Built to grow into Event Planner

This app is the first writer of a shared event data model (the forje-events schema). The upcoming Event Planner app will reuse the same store and backup format, so a date you start here as a countdown can later be opened in Event Planner and fleshed out into a full plan - guests, to-dos, food, venue - with no retyping and no migration.
